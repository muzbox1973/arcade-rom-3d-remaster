## 1. MAME — hardware behaviour (BSD-3-Clause)

Parts of the Galaga reference implementation reproduce hardware behaviour as documented and
implemented in the [MAME](https://www.mamedev.org/) project's source code. The JavaScript in
this repository was written independently and contains no MAME source code verbatim, but its
logic closely follows the MAME files below, so their notices are retained here as required by
the BSD-3-Clause license.

| File in this repository | Behaviour derived from | MAME copyright holders |
|---|---|---|
| `assets/galaga-reference/js/galaga.js` | `src/mame/namco/galaga.cpp` — memory map, interrupt/latch wiring, sprite RAM and tilemap decoding, palette resistor weights | Nicola Salmoria |
| `assets/galaga-reference/js/galaga.js` | `src/mame/namco/namco06.cpp` — Namco 06XX bus/NMI timing | Mike Harris, Aaron Giles |
| `assets/galaga-reference/js/galaga.js` | `src/mame/namco/namco51.cpp` (and the high-level 51XX emulation of earlier MAME releases) — coin/credit and input protocol | Mike Harris, Aaron Giles |
| `assets/galaga-reference/js/galaga.js`, `assets/galaga-reference/js/wsg-remaster.js` | `src/devices/sound/namco.cpp` — Namco WSG register layout and frequency scaling | Nicola Salmoria, Aaron Giles |
| `assets/galaga-reference/index.html` (classic 2D view) | `src/mame/namco/galaga.cpp` — sprite drawing order and coordinates | Nicola Salmoria |
| `references/hardware-bringup.md` | facts about the Galaga board taken from the files above | as above |
