# Arcade ROM 3D Remaster — Claude 스킬

[English](README.md) · **한국어**

**직접 합법적으로 보유한** 고전 아케이드 롬 세트(MAME `.zip`, 예: `galaga.zip`)를 Claude에게
주면, 이 스킬이 다음과 같은 브라우저용 리마스터를 만들도록 안내합니다.

- **원본 프로그램 롬이 수정 없이** 에뮬레이션된 오락실 기판 위에서 그대로 돌아갑니다.
  적의 공격 패턴, 타이밍, 점수, 음악이 원래 기판과 똑같습니다.
- **화면 그리기만** Three.js 복셀 렌더러로 바뀝니다(3D 모델, 조명, 발광, 입체 효과, 게임판 기울기 조절).
- **원본 사운드 칩의 연주를 고음질로 다시 렌더링**합니다(계단 잡음 제거, 딸깍 잡음 제거, 스테레오,
  공간 잔향). 키 하나로 원래 기판 소리와 바로 비교할 수 있습니다.

## 왜 새로 만들지 않고 에뮬레이션하나요?

손으로 비슷하게 다시 만든 게임은 아무리 잘 만들어도 손맛이 조금씩 다르고, 플레이어는 그걸 알아챕니다.
원래 코드를 그대로 돌리면 원작의 감각이 보장됩니다. 3D 화면은 기판의 영상 메모리와 스프라이트 메모리를
**읽기만** 하므로, 아무리 화려하게 만들어도 게임 자체를 망가뜨릴 수 없습니다.

```
사용자 롬 zip ──► 에뮬레이션 기판 (CPU + 커스텀 칩, 원본 코드) ──► 영상/스프라이트 메모리 ──► Three.js 복셀 렌더러
                                                         └──────► 사운드 칩 레지스터 ──► 리마스터 신스 ──► Web Audio
```

## 스킬이 Claude에게 시키는 일

1. **롬 확인** — `scripts/rom_inspect.py`로 어떤 게임·기판인지 추정하고, MAME 드라이버 소스에서
   메모리 구조, 인터럽트, 영상·사운드 하드웨어를 확인합니다.
2. **그래픽 해독 확인** — `scripts/gfx_sheet.py`로 롬 그림을 이미지로 뽑아 눈으로 확인합니다.
3. **기판 재현(2D 먼저)** — 원작의 데모 화면이 뜨는지 글자 덤프와 2D 기준 화면으로 확인하고,
   코인 → 시작 → 점수 상승까지 확인합니다.
4. **사운드 리마스터** — 레지스터를 정확히 재현하고 고음질 신스와 원음 전환을 붙입니다.
   오디오 시계에 맞춰 속도를 조절하고, 음량·잡음·스테레오·안정성을 수치로 검증합니다.
5. **Three.js 렌더러** — 복셀 모델, 미리 돌려 그린 스프라이트 프레임을 하나의 모델 + 방향으로 교체
   (픽셀 겹침 테스트로 검증), 글자 평면, 기판 상태에 맞춘 효과, 부팅 빨리 감기, 자동 맞춤 기울기 프리셋,
   `V` 키로 2D 비교.
6. **실제 키 입력으로 검증**하고, 원작 그대로인 부분 / 근사치인 부분 / 확인 못 한 부분을 **솔직하게 보고**합니다.

## 사용법

롬 zip을 Claude가 읽을 수 있는 곳에 두고 이렇게 요청하면 됩니다.

- "이 고전 MAME 롬파일을 3D 기술을 활용하여 리뉴얼해"
- "Here is my `pacman.zip` — remaster it in 3D but keep the gameplay identical."

결과물은 `index.html`, `js/`, `rom/<세트>.zip`(본인 파일, 공유 금지), `serve.py`, `start.bat` / `start.sh`가
든 폴더입니다. `start.bat`(Windows) 또는 `start.sh`(macOS/Linux)를 실행하면 그 게임 전용 로컬 포트로
서버를 띄우고 브라우저를 엽니다. 여러 리마스터를 동시에 실행해도 다른 게임이 열리지 않습니다.

생성되는 리마스터의 기본 조작키:

| 키 | 동작 |
|---|---|
| 5 / C | 코인 넣기 |
| 1 / Enter, 2 | 1인 / 2인 시작 |
| ← → / A D | 이동 |
| Space / Z | 발사 |
| P · M · O | 일시정지 · 소리 끄기 · 원음/리마스터 전환 |
| V · T | 원본 2D ↔ 3D · 게임판 기울기(탑뷰 → 극적) |

## 한계

- 함께 들어 있는 CPU 코어는 **Z80**뿐입니다. 6502 / 6809 / 68000 등을 쓰는 기판은 새 코어가 필요하고
  (스킬에 인터페이스가 설명돼 있습니다), 시간이 훨씬 오래 걸립니다.
- 일부 기판은 게임 롬 세트에 포함되지 않은 내부 롬을 가진 커스텀 칩을 씁니다(예: Namco 54XX 폭발음).
  이런 부분은 명령 신호를 바탕으로 근사치로 만들며, 스킬이 그 사실을 알려 줍니다.
- 새 기판을 리마스터하는 일은 길고 여러 단계로 된 작업입니다. 결과는 게임마다 다르며, 스킬은 확인하지
  못한 부분(자동 플레이로 도달하지 못한 스테이지, 들어 보지 않고 수치로만 검증한 사운드 등)을 함께 보고합니다.
- 지금까지 처음부터 끝까지 완성한 것은 갤러가 참고 구현 하나입니다.

## 롬 사용 시 주의사항

- **이 저장소에는 롬 이미지가 전혀 없습니다.** 스킬은 Claude에게 롬 데이터를 내려받거나, 결과물에 넣거나,
  재배포하지 말라고 지시합니다. 생성된 리마스터는 사용자가 제공한 zip에서 그래픽·팔레트·사운드 파형을
  **실행할 때마다 읽어서** 씁니다.
- 아케이드 롬은 각 권리자의 저작물입니다. 사용할 법적 권리가 있는 롬만 사용하세요. 예를 들어 직접 소유한
  기판에서 추출한 덤프나, 정식 라이선스로 배포된 세트 등입니다. 백업·덤프가 합법인지는 국가마다 다릅니다.
- 생성한 리마스터를 롬 파일이나 롬에서 뽑아낸 자료(스프라이트 시트, 추출 이미지, 팔레트, 녹음한 소리)와
  **함께 공개하거나 배포하지 마세요.**
- 게임 제목, 로고, 캐릭터(예: *Galaga*, *Pac-Man*)는 각 권리자의 상표입니다. 직접 만든 결과물을 공개할
